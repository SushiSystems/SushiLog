# Documentation style guide

Prose in this repository follows the `humanizer` skill of SushiSkills; where a document goes
follows the `documentation` skill. This page holds what is particular to SushiLog.

| Page | Speaks to | Register |
| --- | --- | --- |
| `README.md` at the root | Someone deciding whether to use SushiLog | What it is, the build line |
| `guides/` | Someone logging through SushiLog or building it | Second person, commands in order |
| A module README | Someone changing the module | Present tense, the code as it is |

A command is written as `sl` spells it. A cited file is a path from the repository root in
backticks. English, British spelling in prose; identifiers keep the code's spelling.
